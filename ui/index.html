Project Purpose

Use these three points while narrating the demo.

1. Save storage with secure dedup

Duplicate chunks are reused instead of being stored again, reducing cost and transfer volume.

2. Prevent fake duplicate claims

Duplicate uploads trigger PoW challenge-response so only real owners can claim existing chunks.

3. Adapt to suspicious behavior

Anomaly detection and policy actions (rate-limit/block) respond live during risky request patterns.
