# Thesis Format Mapping (UG Template)

Use this order in your `ugthesis` format. Keep only required pages as per your department.

1. Title Page
2. Certificate (if required)
3. Declaration (if required)
4. Acknowledgement (optional)
5. Abstract
6. Table of Contents
7. List of Figures (only if figures are included)
8. List of Tables (only if tables are included)
9. Chapter 1: Introduction
10. Chapter 2: Proposed Solution
11. Chapter 3: Methodology
12. Chapter 4: Implementation Summary
13. Chapter 5: Results and Discussion
14. Chapter 6: Conclusion and Future Work
15. References
16. Appendix (optional: API list, screenshots, scenario report snippets)
